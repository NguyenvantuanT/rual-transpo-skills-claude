### Next.js (App Router + React)

- Chạy: `npm run dev` · build: `npm run build` · test: `npm test` · e2e: `npx playwright test`.
- Tự kiểm chứng UI: skill `web-run-and-verify` (dev server + Playwright: chụp màn hình, console, network). Feature nhiều file → subagent `nextjs-web-dev`.

| Việc | Skill |
|---|---|
| Route, layout, Server vs Client Component, metadata | `nextjs-app-router` |
| Lấy/ghi data: fetch server, Server Action, TanStack Query, cache/revalidate | `web-data-fetching` |
| Component, Tailwind/shadcn, form (react-hook-form + zod), a11y | `react-ui-components` |
| Đăng nhập, session, middleware, phân quyền, XSS/CSRF, env | `web-auth-security` |
| Test unit/component (Vitest + RTL), e2e (Playwright), MSW | `web-testing` |
| Chậm, bundle to, Core Web Vitals | `web-performance` |
| Đa ngôn ngữ (next-intl) | `web-i18n` |
| Thiết kế UI/UX, bảng màu, font | `ui-ux-pro-max` · `frontend-design` |
